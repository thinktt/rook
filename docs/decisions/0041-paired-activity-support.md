# Evaluate paired Activity support counting

Experiment56 replaces two private source-square support-count expansions with
one reduction over two independent 16-bit lanes. The public Influence counting
function, supplied maps, state representation, comparison, support penalty,
mobility, relation queries and marks retain their original owners. Each radix
digit pair is at most six; each lane sum is at most twelve. The queen correction
cannot borrow across lanes, and the resulting uncapped count is at most eleven.
The identity covers all byte pairs without an added coherence condition.

The actual generic Activity body shares this arithmetic in all four kind paths
under the common two-color loop. Packing and extraction remain real costs;
Activity shrinks 192 bytes with the same stack reservation. These static facts
establish the selected mechanism, without predicting CPU savings.

new oracle transcription error: curve index 80 was written as 31, while the
released specification requires 29. The engine returned the correct value.
Only that test literal was corrected. The original failure and source snapshot
are preserved; a fresh corrected-source build produces byte-identical engine
image `789943ce`. All ten corrected focused tests pass, with native receipts,
source snapshots and original outputs independently checked.
