# Four-row functional collection setup

`collect.py` is one fixed-study collector/checker, not a23-unit adapter. It was AST-parsed only; no import, native launch or clock measurement ran in preparation. Native rows/CLI and JSON were agreed with the Rust driver owner. Initial authority is false/unbound. Root must create `execution-clearance.json` from the template with exact derivative ELF/source map/build-profile-proof/runtime pins, known-single-process admission and quiet/job-closure flags; candidate62 is not relabelled. The collector's engine mode must be0555. Every native process is launched through unchanged account_native.py, which observes native14 and helperH and records actual wait4 user/system CPU, wall, PID, exit, tasks, argv and before/after ELF hashes. A short verifier that fails the wrapper's real postexec observation stops truthfully; no hidden sleep or retry.

CLI (future root launch only): `collect.py --engine IMMUTABLE_ELF --output FRESH_EXTERNAL_DIR --stage calibrate`; then record its ACTUAL outer terminal at that directory/tool-terminal.json. Collection: `collect.py --engine SAME_ELF --output ANOTHER_FRESH_EXTERNAL_DIR --stage collect --calibration CALIBRATION_DIR/calibration.json`. Use taskset H=0-5,8-13, TMPDIR=/home/legolas/rook2-build-tmp and no active measurement stream. Authority may be stable across both stages or separately updated: each actual authority snapshot/hash is retained; semantic input closure must match exactly across stages. Source/provenance inputs are a flat absolute-path/SHA map rooted in the frozen derivative and its actual build/train/verify/use evidence, not mutable canonical source or old-profile assumptions. Parent owns PGO provenance/source review.

Order: eval-scalar,eval-coherent,position,search. Each row's driver input file is EXACT `workload.request.input` from the unchanged public workload JSON; no expectedProjection, projection selector, artifact identity or source metadata enters native input. Expected values remain outside the driver. Both eval rows use the same public expectation. Verify JSON must be exactly {row,completed:1,projection,sink,work}; measure exactly {row,completed:N,local_cpu_ns,local_wall_ns,sink,work}. Integers use Python exact JSON values, not lossy floats. Complete projections are recursively compared by type, key set, list order and values (a narrow direct adaptation of released exactValue); this does not manufacture outputs for other20 units. Work is independently0/39 N/R for evaluation,0/0 for position,54/234 for search, multiplied by actual completed count.

Calibration is exactly ONE probe per row:256,256,256,1024 invocations. The search probe includes at least three255-generation clear wraps under the source-reviewed reusable Search owner. The count formula aims0.4CPU seconds and is frozen before measurement, with fixed caps,100us minimum probe resolution and rejection if clamping cannot predict250ms..1s. No adaptive second probe, favorable retiming or new row. Collection is exactly16 timed batches (one excluded warmup+three measured per row), each in a fresh process;32 other fresh verify lifetimes bracket them. Thus4calibration+48collection native processes, no crossbatch learned state. Actual batch CPU below50ms invalidates rather than recalibrating. Deviations from target250ms..1s remain visible in retained samples; no sample deletion.

Each child has30s outer bound,4MiB combined output cap (one observed64KiB crossing chunk may be retained), and a single5s TERM/KILL/reap/group-disappearance budget. Unexpected supervision errors take the same cleanup path. Failed cap/deadline/drain/reap observations are incomplete, preserve observed bytes/commands/terminal files, and stop all later work. No forced pass or missing-byte completeness claim. This is a known-single-native-process source premise, not a general escaped-descendant supervisor; no privilege/global setting change.

Outputs retain every raw stdout/stderr, command/input hash, child/controller/native identities/exits, account receipt, before/after semantic closure, calibration counts, warmup and all measured samples. Whole-stage /proc/CPU15/cgroup observations are point context only. Local clock includes real reset/normalization/complete typed output consumption; whole-owned native guard also includes initial preparation/allocation/setup/output/cleanup plus disclosed preexec prefix. Driver source/projection proof establishes the timed observation path; before/after verify calls alone cannot prove timing boundaries or opaque consumption. Collector checks deterministic sink/work across equal-count batches as additional controls, never substitutes that for source review.

Summary JSON/CSV gives local per-sequence CPU/wall and whole-lifetime guard CPU ranges, original reference ranges and descriptive ratios. Search local is Rook2 owned-call including root preparation; only the reference enclosing local metric is compared, narrower controlled-call ratio is unavailable. Evaluation/position chronology overlap does not authorize subtraction, synthetic consumption is never subtracted, PMU/innersearch ratios are not invented.
