# Three-reader raw reduction worker

`raw_worker.rs` is a separate specialization of positive epoch64's proven epoch protocol. The original `colors_worker.rs` remains byte-identical and mode3 therefore has no inactive third reader. Fixed roles are `rook2-raw-0`: WN/WB+BQ plus white shelter geometry; `rook2-raw-1`: WQ+BN/BB plus black geometry; `rook2-raw-2`: WR+BR. Whole color/kind ownership keeps each same-kind presence OR local. Pairing opposite-color queens with minor-piece work and giving rooks their own role supplies three independent demanded jobs, without a peer barrier. Positions with absent kinds, promotions or asymmetric inventories can skew this fixed assignment; there is no adaptive scheduling.

One coordinator owns the initialized Position/Influence Packet. Control serializes publication, output consumption and final close. A request Release and each reader's exact Acquire publish the immutable Packet. Each entire input borrow ends on `compute_input` return before its separate scalar output write and actual done Release. All three matching done Acquires and the matching Published flight under Control precede output reads. Those Copy reads end before Flight becomes None; the next request Release/Acquire carries the reverse edge before output overwrite. Empty jobs take this same actual retirement path. No mutable reference to the whole cell group is formed, and no kernel holds a mutex.

Final close retains Discarding until all three actual parked/exited acknowledgments. Parking rechecks unseen requests under Control; guards never touch cells. Partial startup marks only genuinely unstarted readers retired and joins every started thread. Concrete-loop unwind ends references before terminal publication. Prepublication failure leaves None and advances no epoch; overflow is terminal and drains rather than wrapping. Completion retains the sole-coordinator 4096-spin then predicate-wait policy. Every normal/terminal publisher performs the unchanged unconditional SC latch exchange; waiter registration/re-registration and clearing also use SC exchanges. Notification takes Sleep only after Control is released. No helper cold-waits on completion.

The coordinator reduces the three unrounded RawActivity values once, then composes the two geometry outputs with the complete defender-indexed pressure. Numerical admission and rounding belong to the separately reviewed numerical APIs. All input/output copies, reduction, polling and lifecycle costs remain charged. There are no hot clocks, histograms, counters or per-dispatch allocations. `cold_report()` after joined shutdown reads the actual necessary request/done epochs and fixed roles; it never fabricates progress.

Focused selector `raw_worker::lifecycle_tests` contains 19 controls adapted from the original 21: two histogram-only controls are omitted, the sampled-borrow control becomes an all-three live-borrow control, and all applicable delayed/failure/startup/close paths cover the actual third reader. Existing startup/reuse also checks idle/final cold reports and empty-kind actual retirement. Parent owns numerical, evaluator and scope integration controls. This task performed source edits/review only: no builds, tests, native execution or Git operations.
