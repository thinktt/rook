# Recovery source boundaries

Review closed2026-10-25.23 selected native controls and both bounded pilots pass;
source/image/receipt pins are in `closure.json`. No detected local output/work or
root-state discrepancy within the limits below.

The recorder collapses the uncharged ordinary-to-Q handoff and preserves its
original request/predecessor annotation on the Q call. An entry key carries the
complete Node, reversible history, call variant, exact window, checked annotation,
geometry permission and stable callsite phase. Q's supplied reply inventory is
bound when present. Ordinary scout/retry/IIO and null/mate calls remain distinct;
the lookup index is only an accelerator before complete equality, not identity.

Within this one fixed-completion run, root context/parameters/configuration are
bound to an exact epoch. Mutable shared search dependencies are native TT
probe/store, pawn selection, killer/history updates and native complete ordering.
These remain journal/replay owners. The replay conservatively compares metadata,
full returned Selection and native sorted inventories. It does not weaken the
old comparison rules to improve observed acceptance.

TT replay works on lazily copied groups. Probe metadata is observed before the
native mate-depth raise; replacement, recent and generation semantics share the
actual native Group kernels. Rejection poisons/discards staging. The canonical
base must stay stable for the entire serial attempt; generation/count checks
are additional guards, not general concurrent conflict detection. Successful
commit publishes touched groups only. Pawn and learning copies start from the
current canonical state, preserving earlier commits and irrelevant changes.

Only a fully valid log range and complete recorded output may be reused. The
first dropped event seals a contiguous journal prefix; cursor attempt counts
prevent an empty suffix from appearing complete. Earlier completed descendants
can survive a later ancestor's overflow. Metadata, event and byte caps are
prospective; censored work is reported. Accepted recorded ranges must be disjoint,
and recursive fallback must not retry the same rejected segment indefinitely.

Installing a result rebases the complete additive Stats/EvalStats delta and
publishes retained state plus the demanded call's PV. Parent native logic still
owns its candidate admission, window selection, retry, score/PV updates, learning
and TT store. Recursive candidate/extension/sorting rows are private scratch;
fresh native entries initialize their consumed rows. The exception is an existing
Q reply list, which is explicitly matched at entry. This is a scoped source
argument, not a certificate for arbitrary external scratch or observers.

The independent oracle checks the local completed call, including retained/PV
and raw counter deltas, before accepting a segment; whole-root-candidate state
and outputs are checked afterward. This catches an incorrect local output even
if later overwritten. A semantically accepted discrepancy is fatal. Oracle
entries must not become an extra admission predicate that merely hides unsound
acceptances; trace exhaustion instead censors the whole candidate's reuse.

The local oracle does **not** independently compare all shared state at every
accepted boundary. A transient erroneous write later overwritten could escape
the root-final audit. Imp2-lead explicitly accepted this limit for the finite
NoHost discriminator; the supporting argument is native owner replay and private
commit, with sparse/direct-state controls. Results may say no detected local
output/work or root-state discrepancy, not exhaustive per-segment state
equivalence. Stronger local-effects auditing is required before adoption or
removing the independent oracle.

Immediate call phase and complete callee inputs are bound; the key intentionally
does not require an identical chain of ancestor administrative phases. An exact
callee may reuse a segment produced under a different ancestor retry/IIO phase
when all its own inputs and native observations agree. This is semantic reuse
within the fixed run, not a claim that those administrative occurrences are the
same task. Recorded segments are still consumed at most once.

NoHost, absent timing/control and no node limit are asserted when instrumentation
is active. Logical counter origins may differ, but additive deltas remain exact
in that environment. This does not certify live poll positions, intermediate
paths/commands, stopped prefixes or enabled diagnostic observers. Existing main
and two-thread artifacts remain unchanged.

Expected prototype costs include complete history-key copies, repeated exact
epoch comparison, retained large Event variants, native pawn/learning cloning,
range replay and bounded lookup metadata. They must be measured and disclosed;
they are not lower bounds on all hierarchical recovery designs. Source review
does not establish useful surviving grain or speed.
