# Joined actual-search replica runner

`replicated_control::run` owns three independent Search instances, original-sized TTs, learning state and exact cloned root chronology/history/parameters/config/seed. It never divides TT capacity or starts existing FULL helpers. Each unique collective lane is attached before actual thread entry is announced. The two named peers (`rook2-rep-1/2`) then wait at a cold startup gate. Only after both entries does the owner invoke `before_search`, allowing the driver to gate external placement before any native Search call. TT creation remains inside the unchanged actual `run_seeded_iterations` entry.

The search timer starts immediately before releasing the gate and covers the owner's actual Search, per-lane normal finish and both real peer joins. `join_ns` is the coarse subset after the owner returns through the joins. Initialization, TT allocation/free, duplicated control/finishing and output comparison remain part of whole native lifetime; final cold comparisons/deallocation are outside the search-region interval. This is fixed-completion NoHost seeded search with default Limits, without timed/host-policy claims. The performance instantiation is Search<false> with no trace or future-input sharing.

A concrete peer-handle guard exists before any spawn. Partial spawn/entry failure, callback error or unwind cancels the collective, opens the aborted startup gate and joins every actual started peer. Per-thread catchers cover initialization and entry. Search/history remain outside each search catcher; caught ordinary errors/panics trigger cancellation before these objects are finally dropped. FULL's infallible path already cancels before panicking. No failed Search state is reused and no error becomes a score. Normal Search return alone permits lane finish; separate terminal flags expose missing future collectives. A deliberately shorter actual test lane exercises this divergence. Both library constructor and runner require panic=unwind.

No owner outcome escapes before all peers join. Every Outcome field, each Iteration/Step, raw root return, work record and terminal publication count must agree across replicas; mismatch is fatal. Audit uses Search<true>, first running an independent inline serial Search at the same admitted depth (at most2), with the evaluator's fixed32768-FULL cap. Each replica compares its exact actual FULL inputs/outputs and N/R against that immutable trace. After joins, explicit comparisons check serial Outcome/raw returns, restored exact history, work/stats, TT semantics, learning state and selected child PV. Only the owner's authoritative pawn cache is compared with serial; unused follower caches are outside the invariant. No per-node TT copy or replay journal is added. This finite check does not claim production/timed qualification.

Selector `replicated_control::runner_tests` contains four controls: actual seeded depths1/2 audited against serial; partial spawn plus entry failure/panic; placement callback error/panic; and actual shorter-lane terminal divergence. Test-only startup/exit probes establish joined retirement and are absent from native builds. Collective selector `replica_collective::protocol_tests` retains eight controls after the prospective layout change. Source-only implementation/review was performed; no builds, tests, native execution or Git operations were run.
