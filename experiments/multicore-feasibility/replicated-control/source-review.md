Imp2 reviewed the concrete evaluator/collective/runner and identical driver;
independent Sol owners supplied disjoint numerical/control, collective/runner and
tooling implementations. The lead read scalar ownership, shared finishing,
actual catch/cancel/join and terminal semantics and found no concrete blocker.
These are source findings pending focused/native admission.

Only owner pawn/local calculation is stateful within FULL. Followers preserve
local control, TT, chronological placement, learning, FAST and finishing while
never querying their unused pawn caches. Each FULL uses one typed scalar gather;
all layers publish exactly the same native R once and preserve side pressure /
shelter mapping. Original per-piece/weight/endgame routines are reused. The old
inline chain retains its position between pawn inputs and local scalar terms.

Two-slot reverse edges protect scalar reads even if a peer publishes one epoch
ahead; >=g alone is not permission to read a different parity generation. Actual
same-epoch finish allows trailing readers; future demand sees terminal mismatch.
Each role is nonclonable and owns distinct aligned publication/storage. Failed
ready is never forged, and all-active cancellation has no cold-latch assumption.
The one prospective64B layout has a recorded cold native footprint; its benefit
and cache traffic remain unmeasured until integrated results.

Both native study lib/bin compile panic=unwind. FULL failure cancels then panics,
per-lane catchers cancel ordinary errors/panics, and a pre-spawn peer guard aborts
the startup gate and joins every real handle on all exits. No failing evaluation
returns a number. The parent driver asserts the same unwind policy for controls.
Normal ordinary feature-disabled release policy is unchanged.

Audit compares structured actual inputs/output and N/R, with exact Arc-interned
root signatures; final cold state includes original TT fields, history, learning,
selected child PV, statistics/outcomes and authoritative pawn state. No per-node
TT snapshots. This finite depth2 audit can miss transient unrelated writes later
overwritten; source induction plus final comparisons support the declared pilot,
not full per-node equivalence or depth8 exhaustive validation. Performance has
no serial trace or expected trajectory. Its complete structured result is compared
against both preserved-source modes and matched new controls.

exact except the empty feature declaration/driver addition. All raw performance
is actual fixed-completion NoHost Search, not the original wire/time workload.
