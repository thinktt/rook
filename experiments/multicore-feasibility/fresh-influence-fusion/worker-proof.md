# Fresh Influence fusion worker proof

Source base: the positive epoch64 color worker. Supplied/custom maps retain their original dispatch path and authority. Fresh admission belongs to the private coherent caller; the worker does not infer it.

Each fresh epoch publishes one immutable Position and owns two separate initialized 64-byte row cells. Helper `i` alone writes row `i`, ends its mutable borrow, publishes its exact row epoch with Release, and performs the existing unconditional SC latch exchange. Helpers actively poll both exact row epochs and terminal state, holding neither Control nor Sleep. Matching Acquire reads permit immutable copies into each helper's local Influence. All row references end before the unchanged Activity/opposite-Shelter kernels; all Packet references, including sampled timing reads, end before output publication and done Release.

Only the coordinator cold-waits. It reuses the existing single-waiter SC-RMW/Sleep registration and predicate rechecks for row readiness and completion. It releases Sleep before taking Control, revalidates `FreshProducing`, copies both rows into an owned canonical Influence, and changes the phase to `FreshDelivered`. Completion rejects undelivered fresh work, requires both actual done epochs, revalidates the flight under Control, consumes scalar outputs, and then retires the flight. The next request's Release/Acquire edge carries completed peer/owner row reads and output reads before reuse, including supplied gaps. Final close retains Discarding until both actual parked/exited acknowledgments. Failure/stop never fabricates row readiness or done; peer polling observes terminal state and drains.

The coherent extraction preserves native per-color order, wrapping additions, slider masks and transpose. Scalar rows explicitly reset all 64 bytes, including reuse after a bit-path row. Public scalar construction remains unchanged. Fresh work adds 128 bytes of row writes and three 128-byte row copies (two helper maps and the canonical map), plus row publication, polling and acquisition costs. Existing sampled kernel/ready intervals include this work. There are no new clocks, observational counters, allocations, helper cold waiters or second dispatches.

Focused partition: `colors_worker::lifecycle_tests` has 29 controls: the original 21 supplied-route controls and eight `fresh_` controls covering delivery, supplied gaps/reset, delayed rows/close, owner-copy serialization, partial/postpublication failure, spurious/late notifications, reverse reuse/overflow, and unpublished failure/undelivered shutdown. `influence::coherent::row_tests` has two controls comparing extracted/reused rows against the unchanged scalar builder, including native wrapping and source multiplicity. The existing eight `influence::coherent_tests` are unchanged. Parent owns evaluator, scope and owner integration controls.

Source-only implementation and review: no builds, tests, engine/native execution or Git operations were performed by this worker task.
