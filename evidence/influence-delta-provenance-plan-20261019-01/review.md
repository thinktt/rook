## Factory policy

1. A private current-map scratch wrapper stores one immutable `&'p Position` plus the existing private Option<Influence> payload, starting None **inside each ordinary invocation**. Parent selected the position-bound pointer after reviewing the relabeling hazard; this is ephemeral frame state, not a persistent Node/Position/Search field. No constructor/import/setter may accept a supplied Some, and no DerefMut/inner exposure permits replacing it. Its only fills are the actual fresh builder or a trusted ordinary-child delta. Fill remains at ordinary782/795's original first-demand sites; Some reuses the map. Existing DIAGNOSTICS influence_builds increments once per empty→filled event, with no N/R, observer or cache change.
2. Filling is bound to the immutable position captured when this private scratch is created. Both fresh/delta fills use that bound position; the getter accepts **no position argument**, so a filled view cannot be relabeled. A trusted getter mints ephemeral TrustedCurrent{position_ref,map_ref} only after such fill. It must never certify generic public ensure_influence's return, an incoming Predecessor's raw fields, or a caller's nonempty Option.
3. The private source-audited main-child factory may attest the **co-located actual Node::child construction**, with an explicit same-parent value precondition. At ordinary728 the current snapshot is copied from node.position, and subsequent evaluation changes only Retained. Formal precondition: `parent_node.position == *trusted_current.position`, the certified map is exact for that position, and the child at the linked call is the actual `parent_node.child(root, movement)` result. Keep this proof at main990–1020 and unchanged-placement retry1033–1054. A debug full equality assertion is optional; no runtime hash/160-byte equality admission, broad Node API/refactor, closure or tuple mechanism is required merely to make this value identity type-provable. Arbitrarily paired prebuilt children/raw refs remain untrusted.
4. Only that factory writes the combined link=true, for actual MoveKind::Ordinary children. Store **one bit**, not another ref pair, in the existing Predecessor; its existing position/map/move remain the data inputs. All raw/unlinked constructors explicitly produce false. The capability itself remains ephemeral, with private fields/creation and borrowed lifetime; obtain it for the main factory rather than retaining a second long-lived ref pair beside the existing raw context. It is not retained in Node/Search or copied into persistent state.
5. The link must stay attached to an unchanged parent/map/move/child-placement relation. A private bit with pub(crate) mutable position/influence/movement fields is insufficient: another module could relabel a certified record without clearing true. Make provenance-bearing fields private/read-only outside ordinary and provide an unlinked factory for timed/raw clients. Internal struct updates that change any component must clear/rederive the bit. Main992 must not blindly inherit a bit via `..current`.
