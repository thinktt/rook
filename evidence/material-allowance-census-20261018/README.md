Immutable preparation README defines exact counter branches/lifetimes. Candidate-inventory lifetimes include empty inventories but exclude earlier returns. Each family must satisfy checked<=loops, nonempty<=loops, nonempty<=K<=A, K<=5*nonempty, old=2*A, lazy=nonempty+K<=old, victim-array sums A/K and elementwise unique<=calls. Q also requires nonempty<=loops-checked. Zero-call loops are loops-nonempty. K is summed per-loop cardinality, not globally distinct victim types.

The model compares original2A to lazy1+K for each nonempty loop, with no actual skipped computation. Avoided source endpoint demands are 2A-1-K. Search-segment denominator:
