# Deferred independent game evidence reconciliation

`reconcile.py` reads completed evidence and public data only. It executes no
engine and performs no timing. It has not run against a completed collection.
Its independent parser compares all raw settings, seeds, clocks, moves, semantic
posts and terminal results against the released fixture. It checks the retained
hash/byte/exit/PID chains and recomputes native lifetime and external search
statistics from the underlying receipts, rather than accepting summary flags.

After polling the original tool handle37105 to actual termination, invoke with
an absent `--output` analysis path and retain stdout/stderr. Each of the48
lifetimes remains available, including the12 excluded warmups. All three
measured per-search CPU samples remain visible; any unresolved zero-tick sample
keeps that search's aggregate CPU statistics/rate unavailable. No terminal N/R
or PMU figures are inferred from posts or SearchID. Published reference ratios
are explicitly raw and uncalibrated, with no qualification decision.

These finite independent games do not establish focused continuity or the
full3288-game gate. Wait4 includes the small Python child pre-exec prefix and
the supervisor has point observations rather than continuous descendant
ownership monitoring. Those collection limits remain disclosed.
