## Proposed minimal seams

Keep `Search`, `Node`, `Retained`, `Position`, evaluator results and the Host API/layout unchanged. Add a statically dispatched observer only to a private shared Q recursion, with the current `visit_q` signature retained as a thin `NoTrace` wrapper. The public cold entry accepts a concrete observer and root-parent snapshot; recursive calls use the same generic worker. `NoTrace` has no vector, frame stack, node ID, dynamic callback, allocation or stored search field. Every snapshot/record-construction/PV-copy argument must sit behind a compile-time observer guard; passing expensive expressions to a no-op method alone is insufficient.

The cold observer needs entry, stage, leave and an internal first-node-ordered marker. It owns node numbering and a stack outside production search state. Pass the actual parent's retained snapshot at the child call, with the prepared root pair seeded for node1; never reconstruct it from child age or final score. Reserve each evaluation record on entry, fill stages in execution order and departure on leave, so evaluations remain in entry numbering rather than postorder. Copy each returned PV before its ply buffer can be reused by siblings. Trace JSON has only the specified enter/leave events; do not add candidate/gate events to the response.

Use a small wrapper/body split (or equivalent single exit wrapper) to observe every successful return, including repetition, reversal, ply63, bounds, stand pat, empty lists, early mate and list completion. Body recursion must re-enter the observed wrapper. Preserve existing `history.pop()` before error propagation. On any stop/resource/domain failure discard the whole output rather than returning a prefix. Entry work must be sampled before `charge_node`; actual check status is computed after it today. One low-disturbance option saves the precharge work only in the traced specialization, then emits the entry after the existing charge/check using that saved sample. There is no intervening recursive event, and allowed runs never reach a poll. This avoids moving production charge/admission or recomputing check purely for serialization.

For evaluator stages, add a narrow native generic stage hook around actual full/fast calls, reporting actual before/after Retained and returned Evaluation (or equivalent score/bounds plus R). Keep the existing details/components API compatible and factor one shared selection body; do not duplicate sparse tests/refresh predicates in the adapter. The existing details callbacks alone do not carry stage before/after Retained and cannot borrow the actively mutably borrowed node/evaluator for arbitrary snapshots. Avoid fixing this with RefCell, unsafe reborrows, another evaluation, or deriving state from Finished. A NoStage observer lets ordinary selection retain the same data layout. The terminal-ply fast call also needs this hook. Stage work is zero S/counter plus the actual evaluation's R (prefer actual before/after native counter snapshots); fast R is zero. No second finish or cache probe occurs for tracing.

## Execution order that must survive extraction

Charge one S and clear PV; repetition draw precedes killer clearing, then clear next killers, then guarded reversal, then terminal-ply fast. Checked nodes skip ordinary static work. Other nodes use actual selection, lower-bound return before upper-bound before stand pat, then lower-window raise. Generate pseudo-legal tactical candidates (legal evasions in check); empty-list and pre-order mate returns precede ordering. Mark node1 admitted only after an actual nonempty list reaches ordering; one visited node does not by itself mean this boundary failed.

For each non-check candidate preserve late non-recapture exclusion before special admission/estimate, forced promotion/EP without ordinary capture policy, actual retained-based allowance, optimistic best update before later rejection, checking/recapture/double-check/reply restriction, and final own-king safety. Support/order/projections/rejected moves charge neither relation queries nor child S. Reuse a complete bounded reply list where native code already does; do not regenerate to manufacture a count. Checked evasions bypass these non-check screens. Recurse with negated window and target increment only for a checked parent, preserving enclosing iteration1. Strict best/PV/window rules and final `min(best,savedEvaluationUpper)` remain actual native code; empty/mate returns are separate. The mate tie fixture protects the earlier PV against an equal later score.

## Lifetime, limits and output

Replay public history with native Position transitions into one SearchHistory, then `mark_root` at the reached position. Only then create/bind the fixed-root evaluator and call actual `prepare_root`; public history is not a list of full evaluations. Apply the selected root child through actual Node::child, push its actual move, and capture the parent before searching. Start ply/target1, window[-10000,10000], analysis0, parent-classified capture exception, one fresh learning/pawn lifetime. No sibling begin_search/reset/rollback of the pawn cache: only branch-local node pair/age and history restore. Parent-retained output must come from the parent after its own selected stages, not a prior sibling's departure.

Call the work-segment reset exactly once after parent preparation. Root relation work is excluded; tree enter/leave work is cumulative from subtree entry and evaluation stage work is local. Under the admitted <4096-node bound, searchCounterDelta equals charged S; use the actual native counter view instead of a synthetic node-derived ledger. Set native node limit4095 to reject before charging/visiting the 4096th node, before an otherwise no-op NoHost poll. Reject failure, first-node pre-order return, or PV>63 as whole-request errors. These limits belong only to this cold route. Serialize exact six top-level fields, exact move-kind mapping and six-field trace position projection; the existing `positions::state` has extra identity/order/phase keys and is not the trace output shape. No live publication or root post/move output belongs here.

## Alternatives, cost and preliminary recommendation

Prefer shared generic recursion plus typed cold sink and native stage hooks. It changes roughly two native algorithm modules (`quiescence.rs`, `evaluator.rs`), one cold frontend module/dispatch and focused tests; helper visibility/export work may be needed, but engine/host layouts need not change. Expect several hundred lines of observer/transport/tests and one substantial implementation/review pass; the risk is callback plumbing/return coverage and monomorph code shape, not missing tactical rules. A `Search<...,Trace>` stored field is simpler plumbing but spreads type/layout work through map_host/ordinary/timed callers; an always-present optional Vec/dyn observer adds production state/branches. A separate copied Q evaluator or adapter recursion is unacceptable. Feature-gated duplicate algorithms also create fidelity drift. Whole ordinary search cannot substitute for the required first selected subtree and fresh shared-state chronology.

Proof plan: traced-versus-NoTrace parity from independently prepared identical roots/history for score, PV, work, final node retained and restored history; use subsequent evaluations to detect altered shared pawn lifetime. Assert nesting/entry IDs, actual parent inheritance across siblings, stage order/count/retained transitions and cumulative work. Include empty-stage draws/check evasions, bound priority, ply63, null reversal delegation, optimistic king-unsafe effects, mate ties/clipping, EP/promotions/history chronology, bad full schemas and first-list/resource limits beyond these ten fixtures. Then run the whole official fixture selection, native tests and strict replay/wire as required by the changed native closure, with exact frozen source/binary/input receipts.

NoTrace erasure is a hypothesis until artifacts are inspected. Generic recursion can alter symbol, inlining, stack or layout even with no stored observer, and evaluator stage hooks can perturb hot selection. Compare ordinary generic/default production artifacts to this frozen base under identical compiler/flags/lock; inspect reachable NoTrace call paths for observer state/allocations/extra work and compare code bytes/stack where useful. Retain exact binary differences, rerun the native regression ledger and request measured performance only after correctness. Existing Q-entry validation does not prove new recursive instrumentation free. Parent should choose this narrow shared observer design if the NoTrace artifact review is acceptable; otherwise revise the seam before promotion rather than weaken trace fidelity.
