## Algebra port and safety proof

The independent offline64-lane model passed exhaustive arbitrary byte pairs before this Rust source was written. This port uses the same mask operations: normalized digits sum0..11, cap>=4 to binary4, least-tier priority1/3/5/9/99, saturating packed-byte subtraction, capped-count lexicographic comparison, and favorable/contested masks. The first two one-bit count digits use the exact half-adder `(x0 XOR x1, x0 AND x1,0,0)` rather than a redundant full4-bit add; three subsequent2-bit digits use the literal ripple carry. Underflow clears ALL byte planes, including the preserved lower bits. No classifier loops over lanes, calls scalar relation, loads RELATIONS or reconstructs a fixture answer.
