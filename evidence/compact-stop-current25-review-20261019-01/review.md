# Current25 compact recursive stop: a backend-first discriminator

**A small isolated current25 source trial is defensible, but select its actual return lowering before any CPU pilot.** The mechanism is real: normal WireHost ordinary/Q use caller-provided memory for the successful result, and Q's shared return serializes unused stop payload on successful exits. The available profiles do **not** establish a large removable envelope or a predicted≥.5% gain. Stop-only propagation is not a measured hotspot; the opportunity is the success ABI paid while preserving a possible stop. No implementation is selected by this review.

## Conservative attribution: mixed rows, not removable cost

Closed current25 absolute annotations are valid; old relative reports are not. Whole-lifetime simulated user Ir totals are45,762,253,122 (35) and3,967,850,732 (08), with actual original replay proof. `profile-row-selection.json` records exact exclusive rows; =>callee rows, repeated enclosing function tables, line0 and block0 are excluded.

The first group includes required negation/score return; the second additionally includes argument setup, calls, prologue/epilogue and register restoration. They are two nested mixed envelopes—**never add them**. Neither is a rigorous whole-carrier upper bound, because inlined/standard-library/unidentified attribution can lie elsewhere; neither is a lower bound on savings. The raw profiles record `positions: line`, not instruction addresses, so they cannot isolate the five actual Q stores or assign a dynamic stop rate to the saved windows. E.g the visible08 result.rs/ordinary row1,097,639 is a separate threshold-limited attribution; it is not a measured NodeLimit or stop count. Broad work_clock/engine/function totals contain admission and polling that a new carrier retains and are not added. No entry/call frequency is inferred by dividing Ir or reading line0. No simulated Ir is a CPU/PMU/cycle prediction.

## Smallest useful trial and falsifiers

Use a **private natural enum** with payload-free NodeLimit and unchanged native ErrorKind, plus compact workers shared by all ordinary/Q/null/scout/retry/IIO and observer recursion. Keep public Stopped/results/debug/error APIs rich and do not manually narrow ErrorKind or encode error tags into a score range. Keep shared arbitrary-counter `work_clock::charge_search_unit` unchanged; its `units5/Some3` must return configured3, not5. Convert its result only at the actual Search charge seam; require the compiler to erase that conversion on successful charged nodes. Reconstruct the exact configured `self.limits.nodes` only at outward boundaries: Q public continue/selected/observed, ordinary fixed/seeded, timed ActualEffects and existing crate-facing wrappers. The option stays fixed through recursive unwind/history pops; neither Host nor timing cleanup can substitute another budget. Use Some for an actual NodeLimit origin; no fallback to stats.nodes/zero. Public generic work-source callers keep their original broad primitive contract.

Before considering CPU collection, inspect the **actual normal WireHost** new caller/callee: success should eliminate these output stores/loads (especially Q), rather than relocating a rich16B relay or adding per-node conversion/detour. Account for new register packing, spills, live result across history.pop, root/public restoration, frames and both ALLOW_IIO modes; match observed/no-trace behavior too. If memory success remains or scalar lowering merely exchanges it for comparable relay/spill work, reject before timing. No claim that a smaller source enum alone meets this gate.

Meaningful existing proposed witnesses are configured-limit recovery at counter5/limit3 including repeated continuation and Dfalse, and actual timed4096 HostIo propagation with distinct native kinds plus restored history/timing. Extend via real maximum/Finish/Abort vs fatal NodeLimit, false-IIO refusal, observer stop-without-leave, and public typed/debug errors; success must retain retained-child scout retry and PV/work/output. Public NodeLimit may be any u64 including MAX; recover that configured value, not an assumed score/counter cap. Nonrecursive ordinary::Error::Host carries io::Error/message and is outside this compression. Existing178/strict54/eightwire and affected117 evidence must be fresh matching artifacts if implementation is later selected; no finite fixture closes the representation/provenance proof.
