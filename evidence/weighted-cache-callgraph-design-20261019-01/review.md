# Weighted-cache permission: bounded call-graph design

Basis: production candidate25 source identified by parent as b68ad475; read-only source review on 2026-10-19. This is a wiring proposal, not implemented or compiled, and selects no storage. No performance or layout conclusion follows.

**Judgment:** one Session-only, coherence-gated timed entry can carry a const permission through the existing numerical/search bodies. Public Session ownership alone is insufficient because `states` is public. The parent-selected `Position::validate().is_ok()` gate closes that gap without changing admission: invalid roots take the original false path. Public Search timed, full/custom-map, observed, fixed-iteration and standalone subtree routes remain false. There must be exactly one source-audited creator of the true search instantiation and no persistent permission.

## Entry and coherence

`session.rs:90–112` exposes parameters, states, moves and other settings but keeps `search` private. A safe caller can change `session.states.last_mut().unwrap().board` without updating private attack planes. Consequently changing public `go`/`go_live` directly to unconditional true is unsound. `Position` also exposes lists/counts/fingerprints/starting units (`position.rs:22–34`). Native Session default/setboard/coordinate transitions ordinarily construct coherent values, but the public API does not seal that provenance.

Use a single `pub(crate) Search::run_session_timed(&mut self, position: Position, history: &mut SearchHistory, controls: Controls, limits: Limits) -> Result<timed::Outcome, ordinary::Error>`, called ONLY at the two present Session search calls (`session.rs:508`, `:567`; locate by call expression if lines shift). It has no caller-selectable permission argument. Evaluate `position.validate().is_ok()` once, then dispatch to private `run_work_timed_entry::<true, true>` or `::<true, false>`. The first const is the unchanged ALLOW_IIO capability; the second is ROOT_CACHE. Public `run_work_timed` remains `<true,false>` and public `run_work_timed_without_iio` remains `<false,false>`. No new normalization, rejection, child validation or history policy belongs here. Crate visibility is a source-audited trust boundary, not a Rust guarantee that other crate modules cannot call it; keep precisely two callers.

The existing validator (`position.rs:425–475`) introduces no identified panic for arbitrary safe public field values: counts sum into usize (at most1530) and reject populations above16 before list slicing; every group endpoint is bounded by that accepted total. Invalid squares short-circuit before indexing. Reconstructed legal-tag mailbox equality precedes planes, hash and starting-credit inspection, so malformed raw Piece bytes fail before those operations. Starting credit is at most2 per occupied square and at most32 accepted pieces, hence <=64 in u8. Rule flags validate before ep indexing. Its error Strings are a possible cold invalid-input allocation, but failure selects the original path. A valid yet unusual broad position remains admitted; history consistency and other pre-existing API assertions are not newly certified or changed. Validation proves current-root placement/list/count/plane coherence, not a legal-game history.

`Session::prepare_go` binds settings before extracting the root/history/controls (`session.rs:440–490`; `parameters.rs:102–132`). This is parameter assignment, not sufficient root binding. The authoritative root/context/weights binding is `Evaluator::begin_search` (`evaluator.rs:285–294`) during native root preparation.

## Map and binding proof

True-root map comes only from root-local None scratch and `ensure_influence` (`quiescence.rs:147–155`). Ordinary local scratch starts None (`ordinary.rs:761`), is filled for exactly its immutable local Position at782/795, and never receives `previous.influence`. The raw predecessor map influences pressure guards, but is not the current full evaluation map. Null/main/IIO children are actual Node-produced positions under the same root; parent maps remain borrows for the existing guards only. Scout retry retains the same child, and neither retry nor IIO rebinds root weights.

Q creates fresh None scratch at255; only its own ensure calls (including356) can fill it. Native child preparation/unsafe filtering and recursion420–450 preserve the original placement chronology. A public selector may receive an arbitrary Some map, but it always stays false. Trusted entry therefore requires no invented claim that a general ensure_influence call or any supplied Some certifies its argument. A separate token/map wrapper could enforce more statically, but is not necessary for this narrowly source-audited graph and would add plumbing beyond the chosen scope.

No production descendant in this graph calls begin_search; current production binding is root preparation only. Fixed run_iterations prepares its own false root (`ordinary.rs:559`), and standalone Q/continued/observed routes remain false (`quiescence.rs:133–218`). `begin_sequence` only resets work/PV/timing/stat state, not the weighted epoch (`quiescence.rs:188–195`); keep it that way. A new true entry ALWAYS binds then invalidates, even for the same root/parameters. Existing entries may remain allocated or contain bits after return, but false code must bypass BOTH lookup and population.

## Host and exit ownership

The exclusive mutable Search borrow spans native root preparation, candidate/iteration/retry search and capture. Host trait methods receive only primitive seed/entry, commands and owned records (`host.rs:44–64`), never Search/evaluator/Position references. Work poll first checks max, then consumes one command (`timed.rs:400–463`). Its commands mutate only clock/post/force/pondering or report status; none rebind evaluation parameters. Root captures publish through the same owned Search (`timed.rs:641–651`), without opening a root/context mutation channel. Safe callbacks cannot obtain that same borrowed Search through the API.

The existing timed entry sets timing=None after every Result (`timed.rs:490–499`). Preserve it for both permissions: invalid depth/table failure, no legal roots (after root full), seed acquisition/started failure, ordinary NodeLimit/IO/IIO errors, capture publication/render error, iteration-capacity error and normal root/iteration/poll stops. Graceful HostStop/HostAbort/WorkPoll are converted to timed stops by ActualEffects.execute614–630 after popping history; other errors propagate. No permission field needs clearing and no extra cleanup/clock observation is introduced. A panic is not newly promised recoverable; even if a Search is recovered under an external catch, a later true entry must rebind+invalidate and false routes bypass stale entries.

`go_live` restores the moved Search via map_host and restores Session controls BEFORE returning native errors (`session.rs:554–590`). `map_host` transfers evaluator storage without changing numerical context (`engine.rs:76–116`); it creates no permission. Offline completed_events and live final post/move/result rendering/publication happen after the timed call (`session.rs:515–639`), so their errors cannot continue a true search. Session accept_move changes the game only after search return. No permission can escape in Outcome, child, callback or returned Host. Next go binds and clears again.

## Constraints and alternatives

Do not silently put the true bit on public run_work_timed, public prepare_root/full/select, default visit_ordinary, observed Q, or internal run_iterations. Do not use a stored active bool, parameter signature, supplied-map hash, Session allocation age or begin_sequence as certification. Public states makes a purely nominal Session-only entry inadequate. A sealed ordinary-wire session façade would avoid validation but requires larger ingress/API ownership changes; an explicit lifetime token could constrain crate-internal use but still needs coherent ingress and map provenance. The chosen once-per-go validation plus private const graph is the smallest identified correction to those actual counterexamples.

Remaining implementation proof: inspect all true call sites and every wrapper instantiation, assert bind→clear→root-full ordering, false-path cache noninteraction, A/B/A settings isolation and malformed-root false fallback. Behavioral tests must cover IIO/scout/Q, abort/seed/publication errors and supplied custom maps; backend review must assess true/false monomorph duplication, call/frame growth and validation/startup cost. This review proves source feasibility only, not cache-key completeness for an unchosen payload, numerical equivalence of an unimplemented cache or benefit. Payload dependency/rounding proof from the accepted architecture review remains mandatory.
