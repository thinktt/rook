# Weighted bound-cache falsifiers (design only)

Basis: retained25 and frozen33 design, not old24's broader raw/reweight contract. No tests below exist or have run by this task. Proposed names are labels, not new public APIs. Keep existing numerical oracles; compare against the shared uncached evaluator with identical root binding, native map, Node and PawnCache history. This is meaningful cache-state differential testing, not a forwarding-wrapper equality test.

## Minimal observation needed

Correct outputs alone cannot prove a hit or absence of lookup/population. Use a tiny **cfg(test)-only** optional thread-local event sink at actual private cache allocate/clear/get/insert sites, and a test-only binding marker at the actual fresh binding. Record operation/key and whether get matched; no production field, permission flag, counter, observer or new public accessor. Evaluator-child tests may inspect/poison their private cache. Session tests can read the test sink without exposing Session.search or Evaluator storage. Off by default and absent from non-test builds. Do not treat an event emitted by a forwarding wrapper as proof of a cache-owner operation.

For public bypass, combine a poisoned exact-key entry, a before/after entry snapshot, **zero get/insert events**, and uncached result/state comparison. Empty-slot cases prove no population; matching poison proves accidental consumption would be observable. A moderate wrong activity/shelter plus activityR99999 is a sentinel, not a fixture answer. For live-hit tests require a positive actual Hit event; equality without a hit is vacuous. Wholly test-private calls to an already-private true evaluator body under a fixed genuine binding establish numerical/live-effects behavior only; they must not be mistaken for Session entry permission. Do not add a production enable closure to make tests convenient.

## Six falsifier groups

**T1 `session_scope_requires_validated_fresh_binding`.** In session's child test module, build Session<true> and <false> through idle commands: force, rnd0/md1/tts65536, legal setboard/START, fixed seed. Invoke real go and go_live (recording Host). Require binding→empty allocation or complete clear→root lookup MISS→root insert before any permitted descendant access; no earlier lookup. An already allocated table may be reused, but a fresh-go root lookup cannot hit an old epoch. This detects a completely disabled implementation as well as late invalidation. Negative case: toggle only states.last_mut().starting_units ^=1 on otherwise coherent START; assert validate Err, then actual go with node limit0. Require zero cache allocation/get/insert events and the unchanged old NodeLimit0 path, not normalization or a new validation error. This benign inconsistent scalar avoids malformed indexes. Session.states is public: default construction/Session ownership is not the coherence proof. Public Search.run_work_timed on a valid root remains false too; no cache allocation/get/insert. This checks the ingress chosen by33, not every possible malformed Position.

**T2 `public_mutations_and_supplied_some_never_access_cache`.** Evaluator-child test, both empty table and matching poisoned entry. Use an asymmetric Q/pawn placement (`6k1/7p/8/8/8/3P4/4Q3/K7 w - - 0 1`), and perform a real public root.values[White][Queen]+=37 mutation without clearing. Separately alter private mobility/shelter weights in that child test and rebind parameter/root fields without clearing as old24 did. Important: weights/Weights are private in25; this is an internal adversary, not a public direct-write API. Public Evaluation.parameters alone does not immediately rebind weights; begin_search does. For every existing eight-route matrix in old pure_public_call (full, full_observed, fresh_observed, full/fresh_detailed, and three selector variants), compare Evaluation, Retained, EvalStats and observed Components/details/stages to an uncached evaluator with identical mutations. Selectors use capture_exception=true and Some(custom) to force actual full demand. Test native map and custom profiles [[255;64];2]; establish a native/custom contrast in the uncached Components/R first so the witness is nonvacuous. Require zero get/insert, unchanged cache snapshot, and unchanged supplied scratch. Public prepare_root followed by selected/continued/observed subtree, public fixed/seeded iterations and public timed entry need the same zero-access smoke matrix/source-edge audit; permission must not be inferred from a populated table or timing state.

**T3 `same_board_hits_do_not_freeze_rule_side_or_chronology`.** Inside one honest fixed binding and with native Influence rebuilt for every observed Position, compare true hit with uncached full. Evaluate only endpoints where noted, so an unrelated direct-map collision cannot accidentally evict the target. (a) `7k/8/8/8/8/8/8/R1R4K w - - 0 1`: match each move against native legal generation, then replay a1a2 h8g8 c1a1 g8h8 a2c2 h8g8 c2c1 g8h8. Assert final board/side/phase/AttackBits equal but White rook list order differs; evaluate initial/final only. (b) Castle-rook board `r3k2r/8/8/8/8/8/8/R3K2R w KQkq - 0 1`, replay a1a2 a8a7 a2a1 a7a8; board restores but Q/q rights clear. (c) Start from validated `7k/8/8/8/3p4/8/4P3/7K w - - 0 1`, whose adjacent opposing d4 pawn makes EP retention nonvacuous. Match e2e4 against native legal generation and construct its actual child; assert child EP is exactly e3 and nonempty before binding/evaluating that child. One Node.null_child must clear EP; a second restores the child side while EP remains empty. Assert board/AttackBits/counts/starting_units unchanged across those nulls and retained age advances. Compare only under one genuine binding; this is not a fresh-go reuse claim. START e2e4 would retain no EP and is deliberately not this witness. No invented occupied/wrong-side EP. (d) Asymmetric Q/pawn board above plus null side flip supplies a tempo sensitivity check; require uncached White/Black tempo contrast before claiming that witness distinguishes live side selection. Compare per-visit Components, full result, live age0 update and R. These are proposed native-transition witnesses, not executed geometry or a claim such boards recur during natural search. Add a genuine in-check full/repeat pair for live tempo0; do not fabricate a false in_check inside a permitted path.

**T4 `hit_replays_R_and_keeps_PawnCache_retained_observers_live`.** Reuse old24's concrete A=`7k/8/8/8/6P1/3P4/8/K7 w - - 0 1`, B=`7k/8/6P1/8/8/3P4/8/K7 w - - 0 1`; assert same pawn%128, different identity. Sequence true A,A; public B; true A. The public B disturbs PawnCache but may not populate/evict pure A. Require last A actual pure Hit **and** live pawn replacement, with result/Retained/full Stats/R deltas equal an uncached matched sequence. Also use START twice, whose old24 witness has positive activity R, and assert this witness's actual payload R>0: missing replay must change result/stat charges. Check both D monomorphs (R remains live in D=false). Seed safe stale positional/progress/age19 on paired Nodes while keeping root-valued nonking state correct; full hits must refresh them just as reference. Exercise real fast→full forced selector and sparse initially-full branch, with before/after stage records; one Components/details callback per full and matching Finished result. Public observed APIs stay false; if observing a true hit needs a test-private instantiation of the existing shared full body, label it numerical policy testing, not a permitted public observed route. Single native finish remains also a source-owner obligation. Preserve old key-equality/collision test; do not mistake expected24B payload for emitted layout evidence.

**T5 `fresh_go_rebinds_clears_but_map_host_does_not_grant_permission`.** Reuse one actual Session, reset same board, apply asymmetric mobility/shelter coefficients (e.g271/43 and377/17) and average depth9 before go B, then default+same board for go A again. Compare each result/events/charged work/game transition with a fresh uncached reference following the same commands, seed and work origin—not three reset clocks guessed equivalent. Each new admitted go requires bind/invalidate before its first root access even though placement repeats. Use go_live→map_host(NoHost)→next go_live naturally; storage survival is allowed, inherited permission is not. After a returned go, public evaluator/full and public prepared subtree must remain zero-access. Work begin_sequence within one true timed invocation must not invalidate: root insertion precedes that work reset; source audit and a test event preserve that distinction. Do not require a natural positive hit in a shallow Session merely from expectation; T3/T4 separately force hit liveness.

**T6 `actual_private_timed_exits_leave_no_access_permission`.** Reuse existing Session Queue and RejectPost/recording Host patterns. On START/rnd0/md20, separate Finish and Abort at the first actual poll; assert poll really occurred/command consumed, proper retained answer vs abort/no-move/force behavior, and same results/work/records as false reference. Add coherent node-limit0 and Host acquire_seed/started I/O error: these occur after root preparation, so root cache is already populated before an actual private timed Err. Cover eligible-capture publish failure using existing depth3 post_session witness if the new call graph's error edge differs. After every normal/error return, public full/select/subtree is zero-access, then a new admitted entry repeats placement with changed context and must clear before access. For unwind, call the **actual new crate-private validated timed entry** on a borrowed Search with a Host that panics in started, catch_unwind only in the test, then test public full/select zero-access on the surviving Search (even if old timing remains), map_host and a fresh permitted entry clearing stale contents. Do not merely call a test-made true full wrapper. Separately, real Session.go_live takes Search out before callbacks: panic may leave search=None/vacant clock. It is NOT currently a promise of reusable Session panic recovery; test drop/non-reachable permission without asserting general recovery. No persistent enabled flag should exist to clean up; tests complement the call-graph proof.

## Existing infrastructure and limits

Old24 evaluator tests already provide exact-key/poison/empty snapshots, all eight public routes, pawn collision sequence, selectors/stages and full special-child differentials. Its `pure_cache_placement_reuse_ignores_chronology_rules_and_reweights_live` deliberately permits trusted root rebinds: **do not copy that old raw contract into33**. New weighted true hits may never cross that rebind. Existing25 Session tests cover actual abort queue, live/offline publications and post errors; timed tests cover real poll/resource cleanup; evaluator tests cover retained retry/sibling and stage boundaries. These are reusable structures, not executed33 evidence.

All recommendations remain source test/proof designs; root-clear/permission propagation and coherence induction need source review in addition to tests (see coherence-premise.md). Passing finite witnesses would not prove every public API mutation, every descendant or all unwind recovery, and does not predict CPU/frame/heap benefit. No implementation, Rust parse, build/test/native/profile/binutils/Git/archive occurred here.
