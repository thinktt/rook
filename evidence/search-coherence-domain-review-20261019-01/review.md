# Search coherence domain: conditionally sealable, not universally established

**A single root guard can support an inductive private geometry permission for one actual native search call, without Node/Position fields. Current25 does not already provide that permission at every Search/Evaluator entry.** Public mutability and externally supplied subtree Nodes are concrete gaps. The proof would certify placement geometry only; it does not make Influence/category conversion free or justify reviving35. No architecture, trial or implementation is selected.

## Why existing admission alone is insufficient

Position.board/squares/counts/metadata are public; Node.position is public; Session.states is public (position.rs22–35; evaluator.rs22–24; session.rs95). A caller can insert a black pawn at a4 in the mailbox of `7k/8/8/8/8/8/8/R6K w - - 0 1` without touching private planes/lists. Public activity then sees the blocker through its old mailbox geometry; private planes still see empty a4. A caller can also update mailbox/lists consistently but leave planes/hashes stale. Nothing in Session::prepare_go, Search::new, prepare_root or timed entry validates this.

Public prepare_root returns a mutable Node; search_subtree/continue_subtree later accept an arbitrary &mut Node. A previously coherent root therefore does not certify those separate calls (quiescence.rs133–218). Public full/fresh/observed/select similarly accept an arbitrary Node/map, and ensure_influence deliberately preserves Some(custom Influence) (evaluator.rs296–351,528–667). Search.evaluator.root/parameters are public too; that does not invalidate geometry by itself, but prevents treating evaluator construction as a universal current-position/root-context certificate.

Released normalized setup plus actual transitions supplies a semantic coherence induction for admitted wire histories (position-setup.md13–39; evaluation-moves.md14–35; ordinary-iterations.md243–265,403–415). That is not a Rust API seal. Native legal generation already consumes private planes, so successfully generating a move cannot independently prove mailbox/plane agreement. Joined ingress explicitly admits attacked nonmoving kings and nonpawn EP victims (ordinary-play-ingress.md43–63); do not replace coherence with historical legality or standalone-Q admission.

## Smallest defensible boundary, with costs left explicit

A private Session-to-Search entry could inspect the **current copied root once**, take a trusted private recursive route only on success, and otherwise use the exact old route. No admission error, recompute, list reorder or canonicalization should replace false fallback. A new root must be checked again after public mutation or reset; Search construction, H::ACTIVE and DIAGNOSTICS are not certificates.

Existing Position::validate is a suitable stronger safe guard in source terms: it bounds counts before slicing, checks square bounds/duplicates before indexing, reconstructs canonical tags from lists and compares the mailbox before any board-derived kind/hash operation, then independently decodes planes (425–475; attacks.rs120–127). This rejects malformed tags safely, including invalid low kinds, stale planes and valid high-byte aliases. It is total over safely constructed field values by these bounds. It also checks fingerprints/starting measure/rule flags, more than geometry requires; false must preserve old behavior, not reject such broader public inputs. A weaker plane-only check is insufficient unless it first safely rejects invalid tags: low-four-plane equality alone can represent invalid kind7/15. No new guard implementation is proposed.

The permission must dominate root full, ordinary full, both IIO policies, mate probe, null, scout/retry, Q handoff/recursion and all full-refresh wrappers. Existing public standalone/observed/custom paths remain untrusted; internal observers could preserve a permission only within the same guarded owned-node chain. A private const route or zero-sized proof could express this without per-Node fields; either requires new source-audited edges. A sticky Evaluator/Search Boolean would be unsealed across later arbitrary calls. The existing weighted-cache boundary review provides a similar lifetime argument, not authority to revive that parked cache or its costs.

Chronological source slices, current phase/count/starting ownership, actual opposing king/rook seventh-row selection, native PawnCache, all R and final numerical owners must remain unchanged. Coherence says nothing about supplied Influence correctness: geometry can use certified placement while classification still consumes the exact supplied bytes. Public activity must keep stale mailbox/custom-map/valid-alias and malformed lazy-domain behavior via its old scalar/safe path, with no eager kind panic.

Finally, four existing tag planes can avoid **mailbox-to-geometry** reconstruction on a trusted path. They do not encode normalized Influence profiles or relation categories; no parent-map/category state is added here. Thus this proof does not eliminate35's profile transposition, class setup, sparse value/mark consumer costs or frame growth. Existing AttackBits exposes only a copied view and private planes, so any future geometry consumer needs a narrow immutable owner seam. Root validation, additional true/false monomorphs/propagation,32-byte view transport, decoded masks, and code/frame effects all remain measured-cost questions. Conditional domain feasibility is established; profitability is not.
