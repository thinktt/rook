# Native session, clock allocation and output composition

All 193 selected native cases pass under the engine's release optimization
settings, with test-harness panic unwinding. Earlier development checks also
passed in debug. The receipt identifies generated source/data, released fixtures,
engine/manifest/lock, toolchain/environment and raw results. Every source/data
identity stays stable; the verified archive retains the exact generated crate.
Expected values remain outside the engine, with no fixture-ID dispatch.

This includes the earlier clock/adaptive/random/aspiration math and six actual
timed-search traces. Those six now compare their complete semantic public
post/move trails, including depth token, score, SearchID, capture time and legal
King notation. New checks also cover schedule/allowance arithmetic, ordered
parameter commands, output-score normalization and preformatted PV boundaries.

Persistent composition covers 28 idle clock-setup sequences, three root-go
outcomes, four fresh joined requests, eight clock-seeded session sequences (42 actual searches),
the public inherited-settings companion, and every snapshot/root step of the
three-search ordinary session. The native session computes its allowances,
searches and selected moves; they are never request-supplied answers. Joined
checks compare derived allowances/clock adjustment/seed, terminal N/R and
complete semantic events, including the zero-root fatal arm. They do not yet
compare every portable ingress response field or strict DIAG admission.

The formatter derives legal King tokens, disambiguating with legal alternatives,
using digit-zero castles, direct promotion suffixes and plus for check/mate.
Numeric fields set the actual prefix length. A directed 63-entry PV with a legal displayed prefix keeps
the 59th crossing token at 382 bytes and never consumes an invalid suffix after
that boundary. Separate native tests cover file/rank/full-square disambiguation
and pinned alternatives.

The allowance table contains correctly rounded powers of the exact binary64
base 0.966667. Its generator uses exact rational powers and verifies adjacent
float midpoints/tie parity, rather than accepting fixture allowance answers.
Schedule allocation and active game-clock synchronization use that native
producer. Arbitrary stored opk is excluded from effective admission and actual
search behavior, tested through signed integer extremes.

The native exceptional transition retains White pawn e6 and king a1, with no
Black king, no result, and a distinct fatal continuation on go. Its internal
placement uses all eight FEN ranks; no board dump is part of that public
exceptional command sequence. Literal exit/stream qualification remains open.

The same source passes 122 library and two CLI tests, plus the 1,352 evaluator/
root cases in a separate release test crate. These harnesses unwind panics;
the production build retains panic abort. This is correctness evidence, not
a CPU timing sample or whole-engine qualification. Live stdin/stdout, immediate
posts, commands at 4096 polls, natural POSIX sampling, fine-work post formatting,
strict JSON transport and the full gameplay/performance gates remain outstanding.
