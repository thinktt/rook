# Move evaluation source proposal

This frozen proposal adds only `evaluation.moveSequence` to retained82. The full official addition is 102 cases with 1,894 evaluation records; the combined selection is 83 operations, 4,823 cases from 77 whole fixture files. Eight focused diagnostic tests bring the source unit inventory to 107; native source and its 139-test inventory are unchanged. These are source inventories, not execution claims. Exact paths, case IDs, file/spec hashes, and patches are adjacent.

The harness creates one evaluator, binds parameters once, calls `begin_search` once, and starts with actual `Node::root` plus one actual full evaluation. Each ordinary step resolves native legal generation, applies actual `Node::child` once, and checks resulting material capacity. Each null step requires both kings geometrically safe, then uses actual `Node::null_child`. No placement reconstruction, handcrafted retained inheritance, unrestricted search, or synthetic finishing arithmetic is used. Native position/node code owns chronology, castling, EP, promotion append order, current phase, root-derived incremental squares, reversible counter and independent wrapping evaluation age. Initial setup normalizes flags and preserves the released broad setup admission, including an attacked nonmoving king. Real EP steps retain the existing portable geometry/victim gate. Counter values do not trigger repetition/draw adjudication in this observer.

Every schema, setting, kind and coordinate spelling validates before initial evaluation; actual move legality and null eligibility are checked sequentially against each produced state. No unrequested pawnOrder/phase/retained overrides are admitted. Initial state preserves the setup notation boundary; subsequent state serialization reads the native child. `inherited` snapshots actual child P/G/age immediately before work; `retained` reads actual post-work native data. Full work observes actual selected pawn reuse, base and a single native Finished. Fast work calls the existing actual fast detailed observer, preserving pair/age and using no pawn cache operations or Influence construction. R and reuse come from native details, without reconstructed charges or score-domain rejection.

The shared cold `Kind` parser and single-evaluation record helper are moved from retainedSequence to evaluation_common; its admission and controlled-placement behavior are unchanged. Existing position syntax/legal/EP admission bodies were split into reusable helpers without changing those bodies (recorded byte comparisons). No new native seam, numerical formula, default layout, production monomorph or hot-path source change is introduced. This does not establish ordinary binary equivalence or performance: downstream compiler/link/layout effects still require the parent's artifact review. Native source identity is explicitly bound for any diagnostic build.

The eight source tests cover mixed full/fast/null reuse, inherited/post retained distinctions, root stability and repeated requests; pawn/capture counter resets with independent age; null flag/order/identity behavior; 256-step age/counter wrapping; castling/EP/promotion and incremental square ownership; null checks and portable EP rejection; eager schemas separate from legality; and promotion suffix/capacity checks. No Q routes, search policy or optional operation is added. The parent decides promotion and centrally reviews integration.
