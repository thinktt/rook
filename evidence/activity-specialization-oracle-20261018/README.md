# Static-kind activity coordinate differential

The harness compares10,000 broad constructed placements against our own prior
coordinate-based influence/activity source. Oracle files and the generator are
the same retained implementation used by the earlier arithmetic-width trial;
their origin and exact hashes are preserved. No other engine source or runtime
fixture answers are used.

Complete influence maps, activity pieces/pressure/weighted values and semantic
relation-query counts agree for both moving sides and varied material/weights.
The actual release test image is frozen before execution. Before/after source,
oracle/input and image hashes remain stable, with normal exit recorded in
`receipt.json`. The shared relation primitive has separate exhaustive formula
evidence; this harness does not independently prove that primitive.

This is finite correctness evidence for the isolated specialization, with no
timing, production adoption or qualification claim.
