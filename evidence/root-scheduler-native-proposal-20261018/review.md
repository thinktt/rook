# Native root scheduler source proposal

This isolated source-only prototype replaces actual timed-root ordering/retry/ranking with one native root_schedule::Iteration owner. Parent decision: prototype the compact Position-free scheduler first, retaining timing/publication/terminal control at its exact existing sites. This is the first three-route architecture slice, not the complete five-route implementation. No diagnostic routes are added yet; no compiled or behavioral result is claimed.

Row uses a u16 slot into the existing immutable initial_candidates move vector. That vector already survives in Outcome; no new maintained identity vector or fake Move/Position/Search is introduced. The existing exploration and completed-ranking vectors are moved into one per-iteration owner. All recursive Search/Node/Position/Retained types stay unchanged. Row should remain the old Root's16bytes, but no layout has been measured. New owner/pending locals, identity lookup, inline choices and aggregate ABI can change emitted root code/frame; no performance-neutrality claim.

Policy freezes from absolute N on entry; relations do not select policy. Stable descending-work tail sort is invoked only when beginning candidate index1, after the first normally completed root. The owner chooses unrestricted second-ranked-score windows or native aspiration, permits exactly one restricted nonfirst retry, retains original window for ranking penalty and carries both passes' N delta once. Caller supplies actual adjusted child returns and absolute search work; it never decides retry/ranking itself. Completion returns strict-best flag, best/second, final returned versus ranked scores and original window. Sentinel-10000 ties retain no strict best. An interrupted child does not call returned and its pending row never ranks.

Actual production integration keeps once-per-candidate adjustment/child construction, history unwind per attempt, diagnostic pass recording, ScoreDrop before BestChange, real PV installation, capture-read and fallible publication before captured assignment, root check, easy/ordinary iteration check, Terminal priority and final carryover at existing sites. The work origin moves only across setup statements that consume no native Work. Previous-best is supplied to the new iteration from the preceding complete owner result; it is not rebound to an uncompleted pass. Fixed ordinary_iterations and seeded fixed completion are unchanged.

Three new native tests are declared: policy crossing/delayed stable tail, exactly one retry/original-window fail-low penalty/prior+both-pass effort, and sentinel ties/u16 identity511. They are UNRUN. Rustfmt parsed only the named new owner and timed source (906426 exit0); no cargo/rustc/test/engine/codegen/PGO/profiler ran. The source closure remains based on exact103, whose source tests are also unrun. No root/frozen parent is mutated.

Before execution or promotion: independent architecture/source review, emitted-size/frame/call/layout inspection, native tests, exact controlled3-route schema transports and all65 released cases, full component union and strict54/eightwire24. The later shared timed-event boundary and work activity/poll owner remain required for timedRootSequence/workTimedRootSequence; scalar Adaptive helpers alone do not qualify those routes. Final architectural decisions and integration remain with the parent.
