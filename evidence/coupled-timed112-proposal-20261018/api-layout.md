# Pre-implementation static sequence boundary

One new native timed_sequence module holds a synchronous `drive<E: Effects>(rows:Vec<root_schedule::Row>, maximum_depth:u8, effects:&mut E) -> Result<Option<E::Stop>,E::Error>`. None means supplied-list exhaustion or actual capacity exhaustion for the caller to distinguish. RootIteration is the only owner of root rows/ranking/windows/retry/work attribution. The driver owns previous-best/depth and calls exactly one associated candidate-local Child per candidate, preserving that value through attempts. No runtime action interpreter, trait object or extra Search fields.

Effects associated types are Child, Stop, Interruption and Error. Methods are scoped loans: set_depth; begin_iteration_records; begin_candidate(depth,Attempt)->Child; execute(depth,Attempt,&mut Child)->Returned(score)|Interrupted(reason); record_pass; adjustment; install_best; capture; completed_step; root_check; finish_interrupted; complete_iteration. Driver alone admits and orders these calls: set_depth, RootIteration new, records init, next/begin/execute/retry; on completion restricted-first ScoreDrop, strict-best installPV then BestChange then capture(metadata observation/construction/CaptureSlot); completed step then root check; only full exhaustion easy/iteration observation and shared ordered terminal; previous-best and ranking carry only after continuing. Interrupted executes no pass-return/commit/capture/root or iteration completion; native supplied provider still records its incomplete pass itself.

ActualEffects<'a,D,H,const ALLOW_IIO> borrows `&mut Search<D,H>` and `&mut SearchHistory`, immutable root Node/influence/root Position and initial candidate slice, and owns only the existing local PV Vec, current diagnostic Iteration/Vec and CaptureSlot. Associated ActualChild owns exactly the former candidate-local Node, movement, original window, random adjustment and D-gated passes Vec. begin prepares Node once; execute pushes history, calls visit_ordinary_impl::<ALLOW_IIO>, always pops, and returns normal adjusted score or explicit work/host interruption. Clock loan begins/ends inside each method. No &mut Clock is stored beside &mut Search. finish_interrupted and root/iteration stop effects preserve the old push-record-before-Stop construction sites. Default true/guarded false wrappers and shared timing=None cleanup remain in place.

ControlledEffects<Source> borrows typed original-slot-indexed reply rows, owns scalar Adaptive plus one Source and CaptureSlot<CapturedSlot>; no Position/Move/Node is invented. Source is statically selected supplied-elapsed versus counted-work, each owning its sole N/R and clock state. A typed native reply runner calls the same drive. Cold code owns exact eager parsing/label mapping/JSON only. Native Adaptive observation closures append trace rows only when apply actually observes; initialization is one explicit row; capture metadata invokes source.observe without trace. Controlled complete_iteration uses the actual shared Terminal early prefix, not fake phase/md; production keeps the entire signed Terminal decision and ignores iteration Adaptive's Boolean as before.

Extract one native charge_search_unit(&mut N, Option<limit>)->Result<poll_due,Stopped> and call it both from real Search.charge_node and the native counted Source's relation-first then unit loop. Actual work_poll remains unchanged: max check, host command, maximum stop. Counted supplied source calls real Ledger and Adaptive Poll on due units and interrupts even on its final unit before exposing score. No provider resets N/R at roots/retries/depths and relations never poll.
