This is an offline named-event parser, not a recording authorization. No engine, Valgrind recording, cache model or branch model was executed.

`parse_file(path, expected_events=list)` returns header-ordered named vectors, exact raw SELF rows and separately retained inclusive call arcs. The collector must supply the exact thirteen-event set in schema.json. Missing trailing counters, including all counters omitted, mean zero; Ir-zero rows with other costs remain. Compression is resolved sequentially in shared file/function/object namespaces. Unknown labels remain unknown. Raw source-line positions, names and call target tokens are preserved.

The accepted domain is a complete, single-part, line-only whole-program dump. Every event must reconcile SELF, summary and totals exactly. This is stronger than the general format, which permits partial summaries greater than SELF. Unsupported thread splits, positions, derived events, unresolved/malformed aliases and arithmetic overflow stop parsing. No implicit event order is assumed. Calls vectors are inclusive and never added to SELF.

Ranking deliberately coalesces object/function NAME labels, preserving file partitions and raw name tokens. Distinct physical functions with the same label may merge; neither compressed ID nor inherited callee object is physical-owner proof. No costs or causal relationships are inferred from these labels. Branch-miss ratios have null zero/absent denominators, and simulated counts do not measure hardware behavior or production speed.
