# Unselected pressure occupancy-clipping design

Root owns this design. No candidate, source variant, selection clock, build,
profile or native comparison is selected by this note. The fresh57 pressure
SELF/mapped costs and independent feasibility review remain prerequisites.

The original public Activity compute and all public/observed FULL wrappers stay
on their existing scalar pressure geometry. Existing normal Search geometry
permission comes from validate at the owned root and its preserved descendants;
checked status or a supplied Influence map does not grant that permission.
Thread the existing bool through private full_for_search/full_impl and private
Activity compute_for_search/shared body; public wrappers supply false. Do not
add state, change public Position/Influence layout, infer a map permission or
const-specialize the giant Activity body into duplicate variants. All supplied
Some Influence bytes remain authoritative for marks, mobility and charges.

At the pressure tail only, true selects one private kernel. Borrow existing
attacks::influence_rays(king) masks/increasing-direction references, never copy
64-byte rows. Occupancy is OR of canonical low three type planes. Attacker
occupancy is occupancy intersect color plane (Black), or its complement (White).
For each admitted diagonal/orthogonal ray, intersect occupancy. If nonempty,
choose nearest occupied square using the correct increasing/decreasing bit scan;
clear the blocker’s outward ray from the king ray. Exclude the blocker itself
only when it belongs to the attacker. If no blocker, retain the complete ray.
OR the four clipped masks inside each class; the rays are disjoint away from
origin. Iterate selected targets and apply original PRESSURE_VALUES(mark&mask),
using original0xcc diagonal /0xf0 orthogonal masks. Keep inventory admissions.
Leave the existing scalar knight traversal literal and unchanged. Finish
max(sum−12,0).
No source/move decode, relation query, Influence rebuild or persistent view.

Semantic equivalence obligations: first attacker stops BEFORE contribution;
first defender stops AFTER contribution; empties retain all intervening marks;
king origin is absent; blockers beyond the first do not matter; canonical type
and color planes match mailbox; both kings can be adjacent or attacked where
admitted. Raw mark bytes may be arbitrary, independent of position/Influence.
Addition reordering is safe: every summand is nonnegative and even a loose
2*64*112+8*40 bound fits i32. No observer sees partial pressure. The normal
Activity-bound proof transfers only after exact geometry equivalence.

Required meaningful tests if selected: independent scalar kernel parity on
all squares/colors/admission classes; each first-blocker distance and color,
multiple blockers, boundaries/empty rays, adjacent kings, inventory0/sparse/dense,
all256 mark-byte strata and asymmetric per-square marks. Complete Activity and
FULL parity with arbitrary supplied Influence; public/stale-plane false route
must remain scalar. Existing literal test bodies remain intact. No test should
compare the new kernel to itself. Native wrappers/selection/observers preserve
order, counters, retained state and public behavior; prove flag transport at
root/ordinary/Q sparse/refresh and supplied Some-map call sites.

Backend discriminator: actual bounded generic compute/FULL/native callers
must retain true/false permission meaning, share ordinary scoring work, remove
per-selected-target mailbox/color/offset classification from the true pressure
path and avoid new allocation/copied ray rows/geometry reconstruction. Price
8 nearest-blocker operations, set-bit traversal, mark loads, unchanged knight
work, extra bool liveness/call ABI/frame/spills/text/cold scalar route and
empty/sparse/dense work. The false branch remains fully usable. A source loop
reduction or a smaller frame alone is not a speed claim.

This differs from parked32's static-ray traversal: clipping removes repeated
mailbox/victim/coordinate tests, rather than replacing offset iteration with
an equivalent per-target table loop. It also differs from bitplane generation
and scalar category caching: no pressure result or category is retained. Native
permission transport is a changed private interface and must be measured.
