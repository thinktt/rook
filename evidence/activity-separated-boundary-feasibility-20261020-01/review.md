# Separate Activity boundary — bounded feasibility, unselected

**GO to an isolated source prototype only if the parent selects it; backend-first rejection should precede runtime.** There is a clear discriminator absent in42: separately non-inlined true/false consumers, with a zero-slider branch before entering either coherent body. This is a compiler-placement hypothesis over42's existing geometry algorithm, not evidence that the algorithm is profitable. No current retained43 instruction budget is isolated as removable, and no speed or candidate selection follows.
