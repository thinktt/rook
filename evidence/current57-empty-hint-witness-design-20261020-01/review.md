# Empty-source completion witness: prospective design, NO-GO on present evidence

Do not select this diagnostic run or create its capability now. There is no defensible present expectation that one small-table natural search will produce the required distinct-placement identity match and complete the narrower floor-retained-hint path. This is a finite, UNRUN design, not a public counterexample, probability theorem, new admission rule, or request for native cycles. The existing composed-spec question remains open.

## Why a tiny table is not the missing discriminator

The admitted tts96 gives largest_prime(96/48)=2 groups, each with three retained records and recent (remembered.rs:139–166). Probe checks generation and exact32-bit secondary identity; same group alone does not produce a hint (92–95,230–246). Replacement pressure is not identity-match evidence. At any instant a query considers at most four resident identities, not all identities seen over the search. An independent-uniform heuristic would concern bounded resident/query comparisons, not a birthday N-squared pool; no independence, distribution or likelihood theorem is established for these actual fingerprints. Smaller residency can remove a potentially matching record before its query.

For mod2 the side/EP/rights terms in group_for are multiples of256, so they do not change the group (182–189). Same-placement rule-state reuse is consequently possible without a distinct-board32-bit collision, but its current source squares have not become empty merely by changing rule state. It does not construct the desired absent-source event. Transpositions with identical placement similarly do not by themselves supply it. An already-invalid hint propagated from an earlier completion is a causal chain to investigate, not a source of an initial public witness.

The precise event is ordinary.rs:1091–1095: capped best>incoming L reaches learning.record. The unproved branch has initial preferred from a probe with no usable score (759–769), effectiveLower>L, no generated replacement of that preferred, and an empty source plus empty destination in the *saved parent* Position. Generated-candidate and quiet-mate replacements have a source occupied in that parent. Learning::record currently returns on empty source (ordinary_policy.rs:406–417); observing that existing suppression would not make it normative. remembered-results.md:148–152 leaves collisions/composition outside its direct component diagnostic; cutoff-memory.md:25–34 supplies no absent-piece interpretation.

## One finite prospective witness design

If separately selected after stronger evidence, use one fresh diagnostic-native process running the actual ordinary bin input loop, Session<false>::default, Session::idle and go_live, default Limits and actual WireHost. No custom child answers, table writes, Node mutation, preset N/window, seed override, skipped IIO, or alternate search scheduler. A single canonical START session supplies ordinary admitted history; no setboard or guessed-collision placement is needed for this design. The prospective public command stream is:

    xboard
    new
    force
    easy
    cm_parm tts=96 rnd=0 md=12
    level 0 1 0
    post
    go

This is NOT a launch script or selection. The syntax is accepted by session.rs:317–428 and parameters.rs:63–98; bind admits tts>=96 and nonnegative rnd (101–118). lvl0/1min/0 is an ordinary schedule, not a direct work-counter assignment; md12 is personality depth, not recorded sd/st. Keep stdin open after go. Optional existing --diagnostic-seed-command may log the naturally acquired seed, but send no king_seed assignment. WireHost samples actual seconds+entry once (bin/rook2.rs:18–33), even with rnd0; the choice rnd0 avoids making this experiment depend on the unresolved large-randomness/root-collapse chain. No seed-based timing/wait/retry or result retuning.

The ordinary binary currently rejects unknown options and has no completion event capability (bin/rook2.rs:65–84). In particular a cfg(test)-only library hook does not become active in the ordinary CLI artifact. A future selection would have to explicitly authorize a test/diagnostic build capability on this same CLI path; a library test with a custom Host must not be mislabeled as the exact ordinary CLI witness. No such hook, feature or build exists by this design.

The minimal observer would sit immediately before the *existing* learning.record at ordinary completion, not force its predicate. Record all-completion/floor-retained-hint funnel totals and at most the first target event. The event should retain exact parent board/side and search path, actual query identity/group, remembered score/bound/hint metadata, original L/U and effective endpoints, final capped best/preferred, and a diagnostic-only origin flag showing whether generated/quiet-mate code replaced the inherited hint. Read-only observations must not alter comparisons, calls, N/R, table contents, seed, poll cadence, logical work or return values. Capturing an empty-source event is enough to show that actual composed caller reachability; claiming a particular fingerprint collision additionally requires real prior record provenance, which this minimal observer does not fabricate. Mark that causal origin unknown if unavailable.

Buffer fixed aggregates plus one bounded event in memory; no per-node I/O. Emit to an explicitly selected separate create_new file at normal process completion, outside protocol stdout/stderr; actual PID/schema/completeness/overflow and final work identify the lifetime. File errors, overflow, missing/partial data invalidate the diagnostic, never count as absence. Preserve all command writes, stdout/stderr and exit/status, before/after input pins, observed natural seed and final normal stop/work. No external opaque oracle or private implementation source is involved.

One native lifetime only, no retry. A possible external safety envelope is60s elapsed,1MiB each stdout/stderr/diagnostic output and one full event. If still searching at45s, send one public force, consumed only at the next actual4096-unit poll; then observe Aborting and wait for idle before quit. Do not prequeue force/quit behind go: search-time polling can consume lines, including ignored ones. If the normal stop/abort does not close in the bounded grace, terminate then kill/reap the owned process and classify incomplete, not a negative witness. Early ordinary natural completion closes that one search; send quit only after observing its outcome. No direct node limit, artificial25000 counter, synthetic poll result, reduced u64 domain or clock reset is introduced. Counts/timing would be diagnostic only.

## Interpretation and recommendation

A complete target event establishes one actual own-code Session/go path reaching the unresolved absent-source learned-state consumer; it does not decide the released absent-piece behavior. A complete run without the event establishes only non-observation for that one seed/settings/history/budget. It does not prove native unreachability, a legal hint invariant or a collision bound. A hook with zero events but missing funnel accounting, incomplete output or failed cleanup is not even that negative result.

The low-residency collision premise supplies no useful expected hit rate, and the additional effective-floor/no-replacement/completion conjunction makes it narrower. The prior root-collapse review has only a conditional chain with actual restricted-entry/return correlation open; it is not a free way to manufacture these premises. Therefore recommendation is NO-GO for spending native cycles on this uncontrolled witness search now. Preserve the gap, existing behavior and above prospective design; no hook, source trial, run, fallback, skipped update or moving-piece interpretation is selected.
