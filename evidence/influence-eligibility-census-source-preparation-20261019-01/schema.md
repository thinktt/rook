# Diagnostic aggregate schema, hook_version1

Environment: `ROOK2_INFLUENCE_CENSUS=<fresh absolute file>`. Only normal binary main enables collection. A single create_new/write/flush occurs after run() returns, retaining its original protocol stdout/stderr handling. Failure or incomplete structural state returns exit1 without extra stdout/stderr. No per-node I/O. Disabled mode writes nothing. File includes native_pid (actual native process, not a Python supervisor PID), engine_success, complete, diagnostic_only, live_frames, pending_edges, invalid_or_overflow, totals, joint_bins, limits. Require engine_success/complete true, no live/pending guards and invalid false before interpreting counts.

All counts are additive u64. Missing keys mean0. Global totals/joint sums are checked; IDs and frame native-demand increments also checked. A local Work describes at most the fixed32-source board and bounded masks. Some/foreign events per active normal CLI frame are bounded by existing fixed512-candidate source loops; no arbitrary custom-Host lifetime claim. MAX_BINS2048 is a hard output cohort cap; overflow marks incomplete. Metric vocabulary is fixed source strings plus kind0..5/color0..1; no node IDs/moves/positions are logged per node. The runner should impose a separate conservative aggregate file cap (64MiB is ample for this fixed dictionary), and preserve incomplete files/failures.

`joint_bins` contains `{cohort,counts}`. Producer prefixes are `producer/native_ensure/{coherent|scalar}` or `producer/unassociated_direct/{coherent|scalar}`. Demand and frame cohorts contain frame kind(root/ordinary/q), original actual incoming edge(root_child/main_child/iio_child/null_child/mate_q_child/scout_retry/q_child), board-change class(cells0/1/2/3/4plus), current checked/unchecked/check_unknown, and parent_native/parent_unproven. Root entry and missing/foreign contexts have explicit root_entry/no_parent or unassociated/no_parent cohorts. Demand association failures have explicit no_owner/owner_mismatch. Some-only and unknown contexts never mint availability. Same-node ordinary→Q is counted separately as immediate_edge.same_node_handoff, immediate_changes.cells0 and per-frame/per-demand `same_node_handoff`; the effective prior transition remains in its own cohort. Source equality is only a sanity check after the explicit source-owner ID and actual None completion, never the origin of a certificate.

Expected structural identities (for complete output):

- frames_entered = frames_left = frames_with_native_map + frames_without_native_map = sum(frame.samples).
- frames_left = sum(totals frame_map_status.native_map/some_only/unassociated_map_activity/no_map_events). Same per-row indicators sum to1. frames_without_native_map is the sum of the last three; it is NOT itself no-map demand.
- edges_opened = edges_closed = edges_consumed + edges_unconsumed. Missing-parent edge attempts are edge_without_frame and do not open guards.
- native_none_completed = sum(demand.samples) = native_none_associated + native_none_unassociated + native_owner_position_mismatch. Sum frame.native_demands = native_none_associated.
- ensure_some_events = ensure_some_associated + ensure_some_unassociated. Sum frame.some_events = ensure_some_associated. Unassociated events in a live top frame increment its unassociated_events; otherwise unassociated_event_without_frame.
- producer_completed = producer_coherent + producer_scalar = sum(producer.samples) = native_none_completed + unassociated_direct_producer. Every native None event is paired with one unchanged full-builder completion. Sum producer/native_ensure baseline Work equals sum demand baseline Work, except demand adds eligibility/transport fields. before_native_build's attempts equal completed on a normally successful run.
- sum(immediate_edge.*) and sum(immediate_changes.*) equal frames_entered. Frame entry/exit kind subtotals each reconcile. Constructor counts are separate actual Node.child/null calls; do not equate them with recursive edges (reply probes and retries differ).

Each frame bin has samples, native_demands, some_events, unassociated_events, same_node_handoff and one frame_map_status indicator. Native map status takes precedence over Some, then associated Some-only, then unassociated map activity, then no events. A foreign builder in a live frame remains unassociated, not an authenticated parent map. A genuine native scalar map is distinct from coherent planes; mask work needs both the parent map's recorded coherent path and current coherent path.

Baseline Work: producer_calls, zero_result_payload_bytes128, output_payload_bytes128; scalar_colors+bitplane_colors=2; counter_plane_words_initialized=8*bitplane_colors; transpose_colors=bitplane_colors; full_sources=sum(sources.0..5); full_slider_sources=sum(sources.2..4); full_slider_directions=4*B+4*R+8*Q. pnk_targets and slider normal/weak targets are geometric work units. Scalar slider target counts are explicitly unknown. `carry_plane_updates` counts the existing source loop's plane update slots, not executed instructions. Source_zero/output128 are logical payload units, not store traffic.

Demand eligibility is a ladder: ordinary_or_promotion -> two_cell_shape -> parent_native_available_two_cell -> certified_two_cell_for_masks, with separate no_movement, special_not_two_cell_candidate, not_two_cell_shape, parent_native_unavailable, mask_coherence_unavailable and no_parent_context. checked status is descriptive, not a mathematical exclusion. Child scalar modes still count shape/availability but fine masks remain unknown. Source_kind.0..5 means P/N/B/R/Q/K; remove_mover.*, remove_victim.*, add_mover.* count complete source emissions, including promotion and both colors' captured sources.

Affected unchanged sliders are all matching-kind directions from all collinear origins of both colors, deduplicated per origin/direction and excluding F/T. `affected_origins` and `affected_directions` are conservative geometry discovery. `replay_old_complete_source.*` and `replay_new_complete_source.*` use current numerical slider_masks, including unaffected directions; they are NOT minimal changed-ray writes. There is no nearest-blocker discovery shortcut or separate copied numerical policy.

For each such source, the already acquired old/new normal/weak pair also yields same_normal_targets, same_weak_targets, changed_normal_targets, changed_weak_targets, changed_union_targets, normal_remove_only_targets, normal_add_only_targets, weak_remove_only_targets, weak_add_only_targets. Aggregated identities: changedN=removeN+addN; oldN+newN=changedN+2*sameN (analogousW); max(changedN,changedW)<=changed_union<=changedN+changedW. Normal→weak changes remain two contribution-weight events even when the visited square union is unchanged. No cross-source cancellation is performed. The full F/T remove/add envelopes stay separate.

These outputs count current43 source/mask/carry/transpose/copy exposure at actual demand, including Q/no-map cohorts.
